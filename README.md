# 🚀 Full-Stack GitHub Dashboard & Developer Portfolio

> An all-in-one developer portfolio and real-time GitHub analytics platform. Features a Next.js App Router front end paired with a Node.js Express REST API, MySQL database migrations, and automated GitHub activity synchronization.

---

## 🏗 Project Architecture

This repository is organized as a full-stack monorepo:

*   **`client/`** — Built with Next.js (App Router), TypeScript, Tailwind CSS, Lucide React, and TanStack React Query.
*   **`server/`** — Built with Node.js, Express.js, MySQL, ORM/Migrations, and NextAuth Google OAuth integration.
